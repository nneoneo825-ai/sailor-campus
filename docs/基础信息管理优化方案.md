# 基础信息管理优化方案

## 一、系统定位

### 1.1 业务场景

```
┌─────────────────────────────────────────────────────────────┐
│                    水手校园精细化管理平台                      │
├─────────────────────────────────────────────────────────────┤
│  使用对象：集团领导、学校校长、教务主任等管理层                 │
│  管理对象：学校、年级、班级、教师、学生                        │
│  核心价值：为管理层提供学校基础信息的查询、统计、分析能力        │
└─────────────────────────────────────────────────────────────┘
```

**关键区分**：
| 概念 | 角色 | 说明 |
|------|------|------|
| 系统用户 | 管理层 | 拥有系统账号，登录后使用系统功能 |
| 教师档案 | 被管理对象 | 基础信息数据，不涉及系统账号 |
| 学生档案 | 被管理对象 | 基础信息数据，不涉及系统账号 |

### 1.2 模块功能概览

| 模块 | 页面 | 使用者 | 功能定位 |
|------|------|--------|----------|
| 系统管理 | 用户管理 | 系统管理员 | 管理系统使用者账号 |
| 系统管理 | 组织架构 | 系统管理员 | 管理组织结构层级 |
| 系统管理 | 角色管理 | 系统管理员 | 配置权限和数据范围 |
| 学校管理 | 学校列表 | 各级管理者 | 查看学校概览 |
| 学校管理 | 班级管理 | 各级管理者 | 管理班级信息 |
| 学校管理 | 教师管理 | 各级管理者 | 管理教师档案 |
| 学校管理 | 学生管理 | 各级管理者 | 管理学生档案 |

## 二、现状分析

### 2.1 存在的问题

#### 问题一：数据模型冗余
```
组织架构(SysOrg) ←→ 学校管理(School/Class)
     ↓                    ↓
  学校节点              学校实体（冗余）
  班级节点              班级实体（冗余）
     ↓                    ↓
  数据分散、统计不一致、维护成本高
```

**具体表现**：
- 组织架构中的学校节点存储了学校基础信息
- 学校管理模块可能存在独立的学校数据结构
- 两边数据更新不同步，统计数据可能矛盾

#### 问题二：班级管理入口分散
```
入口1: 组织架构 → 新增班级节点
入口2: 学校管理 → 新增班级
     ↓
  数据来源不统一，容易遗漏或重复
```

#### 问题三：教师档案信息不完整
- 缺少完整的教师资质信息（职称、学历、教师资格证等）
- 任课班级关联关系管理不便
- 缺少教师变动（入职/离职/调动）记录追踪

#### 问题四：学生档案功能薄弱
- 学生基本信息字段有限
- 班级分配和调整操作繁琐
- 缺少学生流动（转入/转出/毕业）管理

#### 问题五：批量操作能力不足
- 缺少教师、学生批量导入功能
- 缺少批量分配班主任、任课教师功能
- 缺少班级批量创建功能

#### 问题六：数据权限粒度不够
- 数据范围依赖组织ID，但组织变更时处理不完善
- 缺少临时授权、跨组织查看能力
- 管理层级级数据权限定义不清晰

---

## 三、优化目标

| 目标 | 说明 |
|------|------|
| **数据统一** | 组织架构作为单一数据源，消除冗余 |
| **信息完整** | 完善教师、学生档案字段 |
| **操作便捷** | 增强批量操作、向导式流程 |
| **权限精细** | 多级数据权限、灵活授权 |
| **追溯可查** | 操作日志、变更历史 |

## 四、优化方案

### 4.1 数据模型优化

#### 4.1.1 组织架构作为统一数据源

**原则**：组织架构(SysOrg)是学校、年级、班级数据的唯一来源

```
┌─────────────────────────────────────────────────────────────┐
│                    组织架构 (SysOrg)                         │
│  ┌─────────┐    ┌─────────┐    ┌─────────┐    ┌─────────┐  │
│  │ 集团节点 │───→│ 学校节点 │───→│ 年级节点 │───→│ 班级节点 │  │
│  └─────────┘    └────┬────┘    └─────────┘    └────┬────┘  │
│                      │                              │       │
│                      ↓                              ↓       │
│              ┌───────────────┐            ┌───────────────┐ │
│              │ SysOrg字段：   │            │ SysOrg字段：   │ │
│              │ • 学校类型     │            │ • 班级名称     │ │
│              │ • 地址信息     │            │ • 扩展信息     │ │
│              │ • 学段设置     │            │   (BaseClass) │ │
│              │ • 联系方式     │            └───────────────┘ │
│              └───────────────┘                              │
└─────────────────────────────────────────────────────────────┘
```

#### 4.2.1 用户管理优化（面向系统管理员）

| 优化项 | 现状 | 优化方案 |
|--------|------|----------|
| 用户创建 | 简单表单 | 向导式创建，自动分配默认角色 |

   - 用户列表显示数据范围标签
   - 支持按组织筛选用户
   - 用户操作日志查看
   - 批量启用/禁用用户
```

├─────────────────────────────────────────────────────────────┤

│  仅本人: 仅查看与自己相关的数据                               │

```

#### 4.3.2 权限继承规则

```
组织层级权限继承：
集团管理员
    └── 可查看所有学校数据
        └── 学校管理员
            └── 可查看本校所有数据
                └── 年级主任
                    └── 可查看本年级数据
                        └── 班主任
                            └── 可查看本班数据
```

#### 4.3.3 特殊权限处理

```
1. 临时授权
   - 授权人：选择被授权用户
   - 数据范围：临时可访问的学校/年级
   - 有效期：开始时间~结束时间
   - 自动过期失效

2. 跨组织查看
   - 支持授权用户查看非所属组织数据
   - 记录跨组织访问日志
   - 可随时撤销授权
```

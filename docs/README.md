### 4. [数据库初始化脚本](../backend/init_sample_data.py) 💾
**快速生成测试数据**

**功能:**
- 创建测试用户 (管理员、教师、检查员)
- 创建组织机构树 (集团-学校-年级-班级)
- 创建德育指标 (14项)
- 创建教学指标 (19项)
- 创建示例学生 (每个班级45人)
- 创建示例德育记录 (100条)

**使用方法:**
```bash
cd backend
python init_sample_data.py
```

**适用对象:** 开发人员、测试人员

**何时使用:**
- 本地开发环境初始化
- 测试环境数据准备
- 演示环境搭建

## 🎯 快速开始路径

### 路径A: 我是新加入的开发人员 👨‍💻

**第一步:** 阅读 [快速启动指南](./quickstart.md)
```
1. 安装必要工具 (Python、Node.js、MySQL)
2. 运行一键启动脚本
3. 验证所有服务正常运行
```

**第二步:** 运行数据库初始化
```bash
cd backend
python init_sample_data.py
```

**第三步:** 登录测试
```
Web端: http://localhost:5173
账号: admin / admin123
```

**第四步:** 阅读 [API接口规范](./api-specs.md)
```
1. 了解API设计规范
2. 查看接口调用示例
3. 准备开始开发
```

---

### 路径B: 我是项目经理 📊

**第一步:** 阅读 [开发计划文档](./development-plan.md)
```
1. 了解项目整体规划
2. 确认时间表和里程碑
3. 评估风险和资源需求
```

**第二步:** 组织团队会议
```
1. 分享开发计划
2. 分配具体任务
3. 建立沟通机制
```

**第三步:** 每周跟进
```
1. 检查进度是否符合计划
2. 识别阻塞问题
3. 调整计划(如需要)
```

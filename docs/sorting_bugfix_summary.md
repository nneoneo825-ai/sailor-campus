# 班级管理排序逻辑Bug修复

## 修复日期
2026-01-31

## 问题描述
初次实现的排序逻辑存在严重错误，导致初中和高中的年级混在一起排序。

### 原始错误逻辑

```python
# 错误：初中和高中使用相同的基准值
def get_grade_sort_value(grade_name: str) -> int:
    match = re.search(r'[初高小](十[一二]?|[一二三四五六七八九])年级?', grade_name)
    if match:
        cn_num = match.group(1)
        return cn_numbers.get(cn_num, 999)  # 这里有问题！
```

**问题分析：**
- "初一" 提取到 "一" → 返回 1
- "高一" 提取到 "一" → 返回 1
- "初二" 提取到 "二" → 返回 2
- "高二" 提取到 "二" → 返回 2

**结果：**
- 初一和高一的排序值都是 1，会混在一起
- 初二和高二的排序值都是 2，会混在一起
- 导致排序完全错误

## 修复方案

### 核心改进：按学段分类，使用不同的排序基准

```python
def get_grade_sort_value(grade_name: str) -> int:
    """提取年级名称中的数字作为排序值"""

    # 小学：1-6
    if '小' in grade_name or grade_name.startswith('小'):
        # 提取并返回 1-6
        return 1, 2, 3, 4, 5, 6

    # 初中：11-13 (在小学后面，避免冲突)
    elif '初' in grade_name:
        # 提取并返回 11, 12, 13
        return 11, 12, 13

    # 高中：21-23 (在初中后面，避免冲突)
    elif '高' in grade_name:
        # 提取并返回 21, 22, 23
        return 21, 22, 23

    # 其他情况
    return 999
```

| 小学 | 小学二年级 | 2 | |
| 小学 | 小学三年级 | 3 | |

| 小学 | 小学五年级 | 5 | |
| 小学 | 小学六年级 | 6 | |
| 初中 | 初一 | 11 | 基准: +10 |
| 初中 | 初二 | 12 | |

## 修复的接口

1. **`GET /{school_id}/classes`** - 获取学校所有班级
   - 修复了年级和班级的排序逻辑
   - 确保按学段分类排序

2. **`GET /{school_id}/grades`** - 获取学校所有年级
   - 修复了年级排序逻辑
   - 确保小学→初中→高中顺序

3. **`GET /{school_id}/grades/{grade_id}/classes`** - 获取年级下的班级
   - 班级排序逻辑保持不变（已经正确）
   - 按班级号从小到大

## 技术细节

### 1. 小学识别

```python
if '小' in grade_name or grade_name.startswith('小'):
    match = re.search(r'[小]?十[一二]?|[一二三四五六]', grade_name)
    if match:
        cn_num = match.group()
        return cn_numbers.get(cn_num, 99)
```

**支持的格式：**
- 小学一年级、小学二年级、...、小学六年级
- 一年级、二年级、...、六年级
- 1年级、2年级、...、6年级

### 2. 初中识别

```python
elif '初' in grade_name:
    match = re.search(r'初(十[一二]?|[一二三])年级?', grade_name)
    if match:
        cn_num = match.group(1)
        return 10 + cn_numbers.get(cn_num, 99)  # +10 避免与小学冲突
```

**支持的格式：**
- 初一、初二、初三
- 初一年级、初二年级、初三年级

**排序值：**
- 初一 → 10 + 1 = 11
- 初二 → 10 + 2 = 12
- 初三 → 10 + 3 = 13

### 3. 高中识别

```python
elif '高' in grade_name:
    match = re.search(r'高(十[一二]?|[一二三])年级?', grade_name)
    if match:
        cn_num = match.group(1)
        return 20 + cn_numbers.get(cn_num, 99)  # +20 避免与初中冲突
```

**支持的格式：**
- 高一、高二、高三
- 高一年级、高二年级、高三年级

**排序值：**
- 高一 → 20 + 1 = 21
- 高二 → 20 + 2 = 22
- 高三 → 20 + 3 = 23

## 注意事项

1. **学段识别优先级**
   - 先检查是否包含"小"
   - 再检查是否包含"初"
   - 最后检查是否包含"高"
   - 避免误识别（如"小初三"会被识别为小学）

2. **基准值间隔**
   - 小学基准：0（1-6）
   - 初中基准：+10（11-13）
   - 高中基准：+20（21-23）
   - 预留了扩展空间

3. **特殊格式处理**
   - 支持"小学X年级"和"X年级"两种格式
   - 支持"初一"和"初一年级"两种格式
   - 优先匹配更具体的格式

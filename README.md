# 水手校园精细化管理平台

学校管理系统的完整解决方案，包含教学指标管理、班级报表、德育考核等功能模块。

## 技术栈

- **前端**: React + TypeScript + Vite + Tailwind CSS
- **后端**: Python + Flask
- **小程序**: 微信小程序

## 功能模块

- 教学指标管理
- 班级报表（年级/校级/校区）
- 德育考核
- 宿舍管理
- 微信小程序数据采集

## 项目结构

```
├── backend/          # Python Flask 后端
├── components/       # React 组件
├── miniprogram/      # 微信小程序
├── src/              # 前端源码
└── deploy/           # 部署配置
```

## 快速开始

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建
npm run build
```

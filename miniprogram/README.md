# 教育检查小程序

一个用于学校德育、教学、宿舍等各项检查工作的微信小程序应用。

## 功能特性

### 首页
- 快速检查记录入口
- 四种检查类型：德育检查、教学评价、宿舍检查、整体检查
- 最近记录快速访问
- 草稿管理入口

### 检查表单
- 支持四种检查类型
- 动态类别和检查项选择
- 实时表单验证
- 保存为草稿功能
- AI分析建议（需配置API密钥）

### 日程安排
- 任务管理（添加、编辑、删除）
- 任务状态切换
- 任务分类标记
- 日期显示

### 统计分析
- 检查记录统计
- 任务完成率统计
- 按类型分类统计
- 可视化图表展示

### 个人中心
- 用户信息展示
- 数据统计概览
- 记录导出功能
- 数据清空功能

### 草稿箱
- 草稿列表展示
- 编辑草稿
- 删除草稿

## 技术栈

- 微信小程序原生框架
- 本地存储（wx.storage）
- 无需后端服务

## 快速开始

### 1. 安装微信开发者工具

下载并安装[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)

### 2. 导入项目

1. 打开微信开发者工具
2. 选择"导入项目"
3. 选择 `miniprogram` 目录
4. 填写项目名称和AppID（可使用测试号）

### 3. 配置AI功能（可选）

如需使用AI分析功能，需在 `pages/inspectForm/inspectForm.js` 中配置API密钥：

```javascript
// 替换为你的API密钥
const API_KEY = 'your-api-key-here';
```

### 4. 运行项目

点击微信开发者工具的"编译"按钮即可运行

## 使用说明

### 创建检查记录

1. 在首页点击对应的检查类型卡片
2. 填写检查表单信息
3. 点击"保存为草稿"或"提交记录"

### 管理日程

1. 点击底部"日程"标签
2. 点击"新建"按钮添加任务
3. 点击任务圆圈标记完成状态
4. 点击任务内容编辑
5. 点击垃圾桶图标删除

### 查看统计

1. 点击底部"统计"标签
2. 查看各类统计数据
3. 切换不同时间范围

### 导出数据

1. 进入个人中心
2. 点击"导出记录"
3. 数据将复制到剪贴板，可粘贴到其他应用

## 设计风格

- 使用渐变色和圆角卡片设计
- 色彩方案：
  - 主色：蓝色系（#3b82f6, #4f46e5）
  - 辅助色：绿色（#10b981）、紫色（#8b5cf6）
  - 背景色：浅灰（#f8fafc）
- 现代化的UI组件
- 流畅的交互体验

## 数据存储

所有数据均存储在本地，包括：
- 检查记录
- 任务列表
- 草稿数据

## 注意事项

1. 首次运行需在小程序管理后台配置服务器域名（如需网络请求）
2. 建议定期导出数据备份
3. 清空数据操作不可恢复
